    FAQ

    Common questions

    Quick answers about ordering, limits, privacy and troubleshooting.

    How do I merge PDF files?
    1. Select or drag-and-drop two or more PDF files into the upload area.
    2. Arrange the files (and optionally their pages) in the exact order you need.
    3. Click Merge PDFs and download the resulting document.
    Are my files uploaded to a server?
    No. Merge PDF is a client-side browser utility — the merging happens on your own device using your browser's processing power. Your documents are not sent to, stored on, or shared with any external server.
    Can I control the page order inside each PDF?
    Yes. Each file card has a Pages field. Leave it blank to include every page, or enter a range such as 1-3, 2,5,8 or 1-3,7 to pick exactly which pages are pulled into the merged document — in the order you type them.
    Why does my PDF fail to load?
    The two most common causes are password protection / encryption and file corruption. Open the file in a PDF reader and remove the password (or re-save it) first, then try adding it again. You can also try re-exporting the document as a fresh PDF.
    Is there a file size or page limit?
    There is no fixed server-side limit, because nothing is uploaded. The practical limit is your device's available memory and your browser's tab capacity. Very large or image-heavy documents may take longer and use more RAM — if a merge stalls, try merging in smaller batches.
    My download didn't start — what should I do?
    Some browsers block automatic downloads. After merging, use the Download button in the result panel to save the file manually. Also check your browser's download permissions and any pop-up/download blocking extensions.
    Can I rename the merged file?
    Yes — use the Output file name field before merging. The .pdf extension is added automatically, so you only need to type the name itself.
    Does the merged PDF have a watermark?
    No. The output is a plain merged PDF containing only the pages you selected — no added watermarks, cover pages or branding.
